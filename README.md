A 100-word monologue for a fantasy villain who is secretly just very tired. The Dark Lord has kept the citadel lit since dawn for a final battle the hero keeps rescheduling — and Grimble still wants his annual performance review. The weariness lives in the voice, the pauses and the small deflections, never in a plain statement of it; the scheme (the eclipse, the seven seals, the crown that drinks starlight) is still very much on.

`main.ts` writes the monologue to `/output/entry.txt` and verifies it against the competition gate (1–600 characters, not only whitespace).

## Run it

```sh
node main.ts
```
